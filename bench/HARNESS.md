# HARNESS — multi-method AL-SRA comparison (al_run.py)

Run: `python3 al_run.py <id> <method> <seed> [--pf 1e-3] [--budget 300] [--pop path] [--batch b] [--cand n] [--out_dir d]`
(`<id>` = prefix, e.g. 578). Output `out/<bench_dir>/<method>_s<seed>.json` (`_pf<target>` suffix when `--pf` != 1e-3).
Check: `python3 test_al.py [pilot.npz]` (bisection, u<->x round trip, beta identity, paired init, posterior-covariance helper). Written 2026-10-19.

## Setting (all methods)
- Population file: X (N x d_s), cap, ok. Rows with `ok=False`, non-finite or non-positive cap are DROPPED (`n_dropped_rows` in the JSON); N in the JSON is the kept size.
- u_x = standard-normal coordinates of x_s (LN: (ln(x/m)+s^2/2)/s, s^2=ln(1+cov^2); N: (x/m-1)/cov; same constants as rv.draw). One demand draw z_S ~ N(0,1) per row, seed 12345 (fixed, so every method/seed sees the same population count). Input Z = [u_x, z_S], d = d_s+1.
- S = s_med * exp(sigma_S z_S), sigma_S = sqrt(ln(1.09)) (CoV 0.30). s_med by bisection so `Pf_RB = mean_i Phi((ln s_med - ln R_i)/sigma_S)` equals `--pf`.
- Margin used by every surrogate: `g = R/s_med - exp(sigma_S z_S)` (g in units of s_med; failure g<=0). For EFF and H (egra, akmcs_h) the margin is further standardised by the median capacity scale c = median over the 12 initial labels of R/s_med (= g + exp(sigma_S z_S), R is observed with every FE call), so eps = 2 sd, the H integral and the EFF stopping threshold `max EFF < 1e-3` are all stated in units of g' = (R-S)/c; c is fixed per run and saved as `cap_scale_c`. References: `pf_rb` (exact given R, CoV `pf_rb_cov`), `pf_emp` = mean(g<=0) over the population (one z_S draw each; `n_fail_emp` failures).
- Budget = TOTAL labels (12 initial + acquired). Initial design = `default_rng(seed).choice(N, 12)` from the population, identical for every method (mc excluded: it samples `budget` rows with its own stream).
- JSON: `pf` (at budget, or final for akss/akis), `n_FE`, `err_rb_pct_pf`, `err_emp_pct_pf` (signed relative %), `pf_stop`/`n_FE_stop`/`err_*_pf_stop` if the method's own rule fired (methods run on to the budget after firing), `traj` = [n_FE, Pf(, posterior CoV)] per refit, `wall_s` (excludes `load_s`), `peak_rss_mb` (whole process, includes the OpenSees import ~200 MB), `n_live` (+`n_live_nonconv`, `t_live_s`) for live FE calls.
- Kriging (reused from ROOT/ak_mcs.py `_kernel`): sklearn GP, C * ARD Matern 5/2, alpha 1e-10, normalize_y, 0 restarts. Change: warm-start theta from the previous fit (speed), jitter fallback 1e-8/1e-6 on Cholesky failure. Candidates = the whole population (chunks of 20000).

## Methods
| # | name | formulas | source |
|---|---|---|---|
| 1 | mc | Pf = mean(g<=0) over `budget` random population rows | new |
| 2 | akmcs | argmin U, U=\|mu\|/sd, 1 point/refit over the candidate pool; stop min U>=2 (non-DoE points). POPULATION ENLARGEMENT (Echard 2011): pool = seeded prefix of the population, size `--nc0` (default 10000; 0 = whole population); when min U>=2 but CoV(Pf_hat)=sqrt((1-Pf)/(Pf*n_pool)) > 0.05 the pool is doubled (capped at N) and the test repeated (no FE spent); if the whole population is already the pool the run is flagged `enlargement_exhausted` and the criterion is accepted. JSON: `enlargements` [[n_FE, new pool size]], `n_cand_stop`, `cov_pf_stop`, `n_FE_stop`/`pf_stop` (Pf on the pool at stop). `pf` = truncated-at-budget result on the FULL population (`pf_cand_budget` = on the pool). Pf = mean(mu<=0) | ak_mcs.py logic |
| 3 | egra | EFF (Bichon 2008, eps = 2 sd; `eff()` from run_acq_variants.py) on the standardised margin g' = (R-S)/c, i.e. mu/c, sd/c; argmax EFF, 1/refit; stop max EFF(mu/c, sd/c) < 1e-3 (DoE points set to 0; if all EFF = 0 falls back to min U) | run_acq_variants.py |
| 4 | akmcs_h | H = \|int_{-2s}^{2s} -ln f f dy\|, f=N(mu/c, (sd/c)^2), eps = 2 sd (Lv 2015, integral form with abs; `hfun()` from run_acq_variants.py but abs instead of clip at 0), argmax H, 1/refit | run_acq_variants.py |
| 5 | akmcsi | batch q=8: pool {U<2} (or 8q lowest U), KMeans(8, n_init 3) on Z, lowest-U member of each cluster; stop min U>=2 | run_acq_variants.py KMEANS |
| 6 | akss | SuS in Z-space, p0=0.1, Ns=2000 (`--n_ss`); level 0 = random population subset (labels are cache hits); next levels by modified Metropolis (uniform width 1) conditional on mu<=b using the current Kriging mean; per level add argmin \|mu-b_next\|/sd, b_next=max(p0-quantile of mu, 0), until min U>=2 or `--ss_cap`=60 points/level or the budget; after the budget the SuS is finished on the frozen surrogate; Pf = p0^k * mean(mu<=0) on the last level; other levels' labels are LIVE `call.run` | new |
| 7 | akis | active FORM: SLSQP min \|u\|^2 s.t. Kriging mean = 0 (fallback: lowest-norm predicted failure among 20000 sphere samples), true g at u* (live) added, repeat <=6 times until \|g(u*)\|<0.05; IS density h=N(u*,I), n_IS=3000 (`--n_is`); enrich argmin U on the IS sample (live) until min U>=2 or budget; Pf = mean((mu<=0) phi(u)/h(u)) | new (Echard 2013 pattern) |
| 8 | bal, bal_lit | pi_i = Phi(-mu_i/sd_i); Pf = mean pi (posterior mean); Var = sum pi(1-pi)/N^2 (independent-points approximation); stop CoV<0.05. `bal` (default) acquisition = one-step lookahead (Kriging believer) over the 24 best of the top-2000 by pi(1-pi): score_j = sum_i [pi_i(1-pi_i) - pi'_i(1-pi'_i)], sd'_i^2 = sd_i^2 - cov_ij^2/sd_j^2. `bal_lit` = the literal criterion max Phi(-U)(1-Phi(-U)), which has the SAME ranking as min U (so it differs from akmcs only in stopping rule and readout). Same stop/readout for both | new, ~25 lines |
| 9 | altab | TabICL-v2 (ckpt in ROOT), input Z, target g; per refit `--cand` random candidates, default min(N, ceil(20/Pf_target)) so that the expected number of failures in the set is >= 20 (20000 at 1e-3, whole population at 1e-4 for N=1e5), score sigma/\|mu\| (sigma=(q95-q05)/2, run_a8u), batch 8 with local penalisation, stall guard; hard readout median-quantile<=0 on all rows (chunks of 50000 < 65536) | a8_eff.py run_a8u, run_pcjoint_a12.py ind_readout |
| 10 | beta_rb | target beta(x_s) = (ln R - ln s_med)/sigma_S = -Phi^-1(P(S>R)) (exact identity, tested), input u_x only (no z_S), EFF acquisition with s=(q95-q05)/3.29, batch 8, local penalisation; readout mean Phi(-beta_median) (RB) | run_pcjoint_a12.py rb_readout (median branch), run_acq_variants.py EFF |
| 11 | rand_krig | 12 initial + random rows to `budget`, one Kriging fit, hard readout mean(mu<=0) | new |

## Known limitations
1. Pilot populations (N=900/1800) are too small to discriminate methods: with 1-15 failures every adaptive Kriging reproduces the population count exactly. Smoke test only.
2. AK-MCS family stops at U>=2 immediately when the 12 DoE points contain no failure and the Kriging is over-confident (observed: stop at 12 FE, Pf_stop=0 on pilot 1311); this is canonical behaviour, reported as is. Enlargement exists for akmcs only (the other Kriging methods use the whole population as pool); with N=1e5 and Pf=1e-3 the CoV of the population count is 0.10, so akmcs will normally end `enlargement_exhausted`.
3. H has no verified stopping threshold in the paper; `akmcs_h` stops at min U>=2. H depends on the unit of g (ln sd term); the unit is c (median capacity scale from the DoE), a choice, not from the paper.
4. bal: independent-points variance ignores posterior correlation (CoV under-estimated); lookahead candidate set is the 2000 highest-variance rows.
5. akss: Ns=2000 gives an intrinsic SuS CoV about 0.1-0.2 at Pf 1e-3 regardless of the surrogate; level-0 enrichment around the 10 % quantile of a dense bulk can consume the whole per-level cap (60) and starve later levels at small budgets (budget 60 on pilot 1311 -> Pf=0). `n_FE_stop` only when every level converged within cap/budget.
6. akis: single IS centre (multi-modal failure sets give bias); Kriging extrapolation can predict spurious failures with large IS weights (pilot 1311, budget 120: Pf 0.64 vs 0.01). Live points that fail to converge are labelled capacity 0 (failure) and counted in `n_live_nonconv`; OpenSees prints convergence warnings to stdout.
7. altab/beta_rb: candidate-set size now scales with Pf (see table); TabICL cost grows with it (up to the whole population at 1e-4). beta_rb EFF boundary is beta=0 (p=0.5), not where the Pf mass sits (see memory a12 note: acquisition is second-order there). No CQR/Jensen correction in either TabICL readout.
8. Non-converged population rows are dropped, which removes any pathological-failure mass from both references; the demand draw z_S is shared by all seeds, so seed-to-seed spread excludes demand-sampling noise (except mc).
9. Pf target 1e-4 only changes s_med; the empirical count then holds about 10 failures in N=1e5, so use `err_rb` as the primary error.
10. Each Kriging refit predicts on all N rows: cost grows as n^2 N; chunking keeps RSS about 2.8 GB at N=1e5.

11. akmcs trajectory `traj` Pf is on the current pool; `n_cand_stop`/`cov_pf_stop` also appear (pool size N) for the other Kriging methods.
